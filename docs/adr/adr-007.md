# ADR-007: Agent Tracking?


## Status
Accepted.

## Context
How do we keep track of what the agents do? Versus what humans are doing.

## Decision
Add an agents table and have each user (human or agent) register with our CLI tool.

## Consequences
This makes our product a little less usable in the sense that the user would need to register themselves. However, we believe the tradeoffs are worth it, because now we can track agent vs human actions. This allows our issue tracking db to keep a proper log of everything happening with the issues.
