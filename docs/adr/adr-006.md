# ADR-006: Git integration?


## Status
Accepted.

## Context
As we currently do not have a fully working MVP, a git integration into our product seems a bit too large of a scope for our project.

## Decision
No git integration.

## Consequences
We decided against git integration in order to better focus on the core functionality of our CLI tool. While a git integration would be nice and helpful, it just might be beyond the scope for this project. If time wasn't such a big constraint, a proper git integration would've been great to add.
